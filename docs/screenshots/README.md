# Skrinshotlar / Screenshots

Bu papkaga ilovaning skrinshotlarini joylang — ular README'dagi "📸 Ko'rinishi"
bo'limida ko'rinadi.

## Kerakli fayllar (nomlari aniq bo'lsin)

| Fayl nomi | Nima tasvirlansin |
|---|---|
| `main.png` | Asosiy oyna: suhbat, agentlar ro'yxati, yuqoridagi tablar |
| `settings.png` | ⚙ Sozlamalar oynasi (agent qo'shish) |
| `agent-mode.png` | Agent loyihada fayl o'zgartirayotgani (diff / ruxsat so'rovi) |
| `phone.png` | Telefondan boshqarish (QR-kod yoki telefon brauzeridagi chat) |

## Tavsiyalar

- Format: **PNG**, kengligi ~1200–1600px.
- Qorong'i mavzuda oling (ilova shundayam qorong'i).
- Maxfiy ma'lumot (API kalit, shaxsiy yozishmalar) ko'rinmasin.
- Hajmi kattalashsa, siqib yuboring (masalan [tinypng.com](https://tinypng.com)).

## README'da qanday ko'rinadi

Fayllarni qo'shganingizdan so'ng, asosiy `README.md` (va `README.en.md`,
`README.ru.md`) dagi "📸 Ko'rinishi" bo'limidagi HTML-izohni (`<!-- ... -->`)
oching — rasmlar o'zi chiqadi. Namuna:

```html
<img src="docs/screenshots/main.png" alt="Asosiy oyna" width="800">
```
