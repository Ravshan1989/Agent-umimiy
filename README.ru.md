## 📌 Что это?

**Agent Umimiy** — это настольное приложение, которое собирает несколько AI-агентов в одном месте.
Не нужно открывать отдельный сайт или программу для каждого сервиса: всё в одном удобном окне с тёмной
темой. Интерфейс пока **на узбекском языке**.

Приложение **само находит** агентов, уже установленных на вашем компьютере — ничего вписывать не нужно.

## 📥 Установка

**Windows 10/11 (64-бит)**

1. Скачайте **`AgentUmimiy-Setup.exe`** со страницы
   **[последнего выпуска](https://github.com/Ravshan1989/Agent-umimiy/releases/latest)**.
2. Дважды щёлкните файл и установите: на рабочем столе появится ярлык «Agent Umimiy».
3. Если Windows предупредит: **«Подробнее»** → **«Выполнить в любом случае»**.

> [!NOTE]
> Предупреждение Windows появляется потому, что приложение не подписано цифровой подписью — это обычное
> дело для новых и независимых программ.

**Linux (64-бит)**

1. Скачайте **`AgentUmimiy-Linux-x86_64.tar.gz`** со страницы **[последнего выпуска](https://github.com/Ravshan1989/Agent-umimiy/releases/latest)**.
2. Распакуйте и запустите: `tar -xzf AgentUmimiy-Linux-x86_64.tar.gz && ./AgentUmimiy/AgentUmimiy`
3. Чтобы вставлять скриншоты через Ctrl+V, установите `xclip` (X11) или `wl-clipboard` (Wayland).

**Телефон (iPhone, Android)**: отдельного приложения нет. Запустите [веб-сервер](#веб-сервер-много-людей-в-локальной-сети) на компьютере или сервере и пользуйтесь на телефоне как приложением.

## ⚙️ Настройка

### Добавление агента

При запуске приложение само ищет имеющихся агентов. Остальных добавьте через **⚙ Настройки → ➕ Добавить**:
выберите тип, впишите API-ключ, нажмите **Проверить**. API-ключ можно задать и через переменную
окружения:

| Сервис | Переменная окружения | Модель по умолчанию |
|---|---|---|
| Anthropic (Claude) | `ANTHROPIC_API_KEY` | `claude-sonnet-5-5` |
| OpenAI | `OPENAI_API_KEY` | `gpt-4o` |
| Google Gemini | `GEMINI_API_KEY` | `gemini-2.0-flash` |
| Ollama / LM Studio | не нужно (локально) | модели на вашем компьютере |

### Управление с телефона

1. Откройте и включите в приложении раздел **«Управление с телефона»**.
2. Телефон и компьютер должны быть **в одной сети Wi-Fi**.
3. Отсканируйте QR-код с экрана камерой телефона.

Доступ защищён секретным ключом (токеном).

### Где хранятся настройки?

```
%APPDATA%\AgentUmimiy\agents.json
```

### Инструкции проекта

Если в папке проекта есть файл `CLAUDE.md` или `AGENTS.md`, агент всегда учитывает его.

## 🔒 Безопасность

- Агент меняет файлы **только в выбранной вами папке проекта**.
- Запуск команд и запись файлов выполняются **с вашего разрешения**.
- Браузер работает в отдельном профиле — он не трогает данные вашего основного браузера.
- Ваши API-ключи хранятся только на вашем компьютере.

## 📖 Подробное руководство

### Работа с проектом (помощник в программировании)

Кнопкой **«Выбрать папку проекта»** вверху выберите папку своего проекта. После этого агенты (Claude,
совместимые с ChatGPT, Ollama) сами:

- **читают** папки и файлы, **ищут** внутри кода (без спроса);
- **создают / редактируют** файлы и **запускают команды** (тесты, установка...) — **каждый раз спрашивая
  разрешение**, с показом изменений (diff);
- кнопка «Всегда разрешать в этом чате» отключает запросы разрешений; кнопка **■** останавливает работу.

Безопасность: агент работает только внутри выбранной папки (не выходит наружу, не трогает `.git`). В
режимах «Все вместе» и «Совет» несколько агентов работают одновременно, поэтому они **только читают**.
CLI-агенты вроде `claude`, `codex` запускаются в выбранной папке.

Кнопка **Git**: что изменилось (простым языком), просмотр изменений, **Сохранить (commit)**,
**Отправить (push)**, **Получить (pull)**. Git должен быть установлен на компьютере (git-scm.com);
пароли берутся из ваших настроек Git.

### Чтение и анализ файлов

| Файл | Что читается |
|---|---|
| **Excel (.xlsx)** | все листы, даты (2024-03-15), числа, логические значения; вычисленный результат формул |
| **PowerPoint (.pptx)** | заголовки слайдов, текст, таблицы, заметки докладчика |
| **Word (.docx)** | заголовки (#), списки (•), таблицы |
| **CSV/TSV** | разделители `,` `;` Tab и кодировки UTF-8/Windows-1251 определяются автоматически |
| **PDF** | текст; для сканированных PDF отправьте страницу как изображение (Claude/GPT-4/Gemini прочитают сами) |
| **Изображение** | модели, которые умеют «видеть» |

Для больших таблиц в папке проекта агент использует особые инструменты: **`analyze_data`** (столбцы,
типы, пустые ячейки, мин/макс/среднее/медиана/сумма, самые частые значения) и **`read_table`** (чтение
строк по номеру или поиск по тексту). Большие текстовые файлы (3 МБ+) читаются по частям. Вместо
прикреплённой очень большой таблицы выдаются её анализ и первые строки.
**Ограничения:** старые форматы `.xls/.doc/.ppt` не поддерживаются (пересохраните в новом формате);
чтение текста внутри изображения (OCR) зависит от модели; качество анализа зависит от мощности выбранной
модели.

### Изображения, PDF и файлы

Кнопкой **＋** в поле ввода прикрепите **изображение** (PNG, JPG, GIF, WebP), **PDF**, **Word (.docx)**
или **текстовый файл** — агент посмотрит на них и ответит. Изображения видят Claude, совместимые с
ChatGPT модели, Gemini и модели Ollama с поддержкой зрения. Текст PDF отправляется и другим моделям.
Ограничение: изображение ≤ 5 МБ, PDF ≤ 20 МБ.

### Создание файлов (Word, Excel)

Попросите у агента документ или таблицу: «Сделай из этих данных таблицу Excel», «Напиши письмо в Word». Агент создаёт готовый файл **.docx** или **.xlsx** (и текстовые: .txt, .md, .csv, .html) и показывает его в чате.
- **В окне программы:** файл сохраняется в папку `Документы\Agent Umimiy`; щёлкните строку в чате, чтобы открыть.
- **На веб-сервере:** в чате появляется ссылка «Скачать»; файл может получить только владелец этой беседы.
- Существующий файл никогда не перезаписывается: к занятому имени добавляется номер.
- **Живой просмотр (на веб-сервере):** созданная агентом страница или диаграмма (`.html`) и таблица (`.xlsx`, `.csv`) сразу открывается в панели рядом с чатом; кнопка «Ko'rish» (Просмотр) в строке файла открывает её снова. Чтобы получить диаграмму, попросите: «Построй диаграмму по этим числам». Страница работает в песочнице: у неё нет доступа к вашим беседам и учётной записи. В окне программы щелчок по файлу открывает его в браузере или Excel.
- Работает с агентами, поддерживающими инструменты (Claude, OpenAI-совместимые, Ollama); с Gemini и CLI-агентами пока нет.

### Интернет

Агенты могут **искать в интернете** (DuckDuckGo) и **читать страницы**, а при необходимости предлагают
**открыть страницу в вашем браузере** (с разрешения). В настройках это можно отключить. Безопасность:
доступ к компьютеру и внутренней сети (localhost, 192.168.x.x и т.п.) запрещён; текст на странице
воспринимается только как информация, а не как «команда».
Для нажатия кнопок и заполнения форм на сайтах см. раздел «Агент работает в браузере» ниже.

### Сохранение бесед, инструкции, план

- **Сохранение:** беседы (вкладки, история, проект) хранятся в `%APPDATA%\AgentUmimiy\chats.json` и
  восстанавливаются при повторном открытии приложения (последние 15 бесед). В настройках можно отключить
  или очистить историю. Файл не зашифрован: не пишите секретные данные или отключите сохранение.
- **Инструкции проекта:** если в папке проекта есть `CLAUDE.md`, `AGENTS.md` или `AGENT.md`, агент читает
  это автоматически и следует правилам.
- **Карта плана:** в многошаговой работе агент показывает список «План» и отмечает этапы.
- **Markdown:** заголовки, списки, таблицы, `код`, ссылки и блоки кода красиво отображаются в ответах.

### Управление с телефона

**Настройки → «Управление с телефона» → Включить.** Приложение показывает QR-код: отсканируйте его
камерой телефона (телефон и компьютер в одной Wi-Fi), и чат откроется в браузере телефона. Оттуда вы
пишете, отправляете файлы/изображения, останавливаете работу, переключаетесь между беседами и
**отвечаете на запросы разрешений («Файл будет изменён», «Будет запущена команда»...) с телефона**: окно
на компьютере закрывается само.
- Компьютер должен быть включён, а приложение открыто. Настройки, добавление агентов и плагинов — только
  на компьютере.
- Доступ по длинному секретному ключу (`t=...` в QR): неверные попытки блокируются. **Ключ как пароль**:
  если кто-то его увидел, нажмите «Новый ключ».
- Соединение **не зашифровано (HTTP)**: используйте только в доверенной домашней сети Wi-Fi (не в
  кафе/публичных сетях). Для использования вне дома настройте зашифрованный туннель, например Tailscale.
- Если брандмауэр Windows спросит в первый раз, разрешите для «Частных сетей». По умолчанию выключено.

### Веб-сервер: много людей в локальной сети

Запускаете программу на одном компьютере или сервере, люди в сети работают через браузер (устанавливать ничего не нужно).

**Из окна программы:** Настройки → **«Веб-сервер»** → **Включить**. В окне видны адреса и код приглашения. После включения сервер запускается сам при каждом открытии программы.

**Без окна (на сервере):**

```bash
python -m agent_umimiy --serve            # по умолчанию: все сети, порт 8080
python -m agent_umimiy --serve --port 9000 --host 192.168.1.10
```

Программа выводит адрес и **код приглашения**. Люди открывают адрес и регистрируются с именем, паролем и этим кодом. У каждого свои беседы, ответы появляются по мере написания, можно прикреплять файлы и скриншоты (Ctrl+V).
- Агенты и API-ключи берутся из `agents.json` на этом компьютере: все используют **ваши ключи и ваши лимиты**.
- Для безопасности в веб-режиме агенты **не трогают** файлы, команды, браузер и плагины сервера; CLI-агенты (`claude`, `codex`...) в списке не показываются. Чат, анализ файлов и веб-поиск работают.
- Данные хранятся в `server.db` (SQLite) в папке настроек. Пароли хранятся в виде хешей.
- Соединение **не шифруется (HTTP)**: используйте только в доверенной локальной сети. Чтобы открыть в интернет, поставьте перед сервером HTTPS-прокси (Caddy, nginx). В Windows разрешите порт, если брандмауэр спросит.

**Как приложение на телефоне (PWA).** Откройте адрес сервера в браузере телефона и добавьте на главный экран:
- **iPhone (Safari):** кнопка «Поделиться» → **«На экран "Домой"»**.
- **Android (Chrome):** меню (⋮) → **«Установить приложение»** или **«Добавить на главный экран»**.

Появится значок Agent Umimiy, он открывается на весь экран. На Android полноэкранный режим работает только по адресу **HTTPS**; по обычному `http://192.168...` значок открывает вкладку браузера.

**HTTPS и работа вне дома.** Проще всего [Tailscale](https://tailscale.com) (бесплатно). Установите его на сервер и телефоны, затем выполните на сервере `tailscale serve --bg 8080`: появится защищённый адрес `https://...ts.net`, открытый только вашим устройствам.

### Плагины (MCP) и навыки (skills)

**Плагины.** Кнопка **Плагины** на левой панели: «Добавить» → выберите готовый шаблон (Файлы, Память,
Документы/Context7, Notion, Playwright, GitHub...) или введите любой MCP-сервер сами (команда или URL,
при необходимости ключ). Приложение запускает сервер и отдаёт его инструменты всем агентам.
- **Читающие** инструменты работают без разрешения, **изменяющие** спрашивают каждый раз (есть кнопка
  «Всегда разрешать этот плагин»). В режимах «Все вместе» и «Совет» работают только читающие.
- Для плагинов, начинающихся с `npx ...`, на компьютере нужен **Node.js** (nodejs.org); при первом
  запуске пакет загружается (1–2 минуты).
- Ключи (`NOTION_TOKEN`, токен GitHub...) хранятся только в файле настроек на этом компьютере.
- **Ограничение:** готовые подключения на claude.ai (Gmail, Google Drive, Calendar...) привязаны к вашему
  аккаунту claude.ai, их нельзя перенести в это приложение. Вместо них вы подключаете собственные
  MCP-серверы этих сервисов (со своим ключом). Удалённые серверы, требующие OAuth (кнопка «Войти» в
  браузере), пока не поддерживаются.

**Навыки.** Папка с файлом `SKILL.md` (формат Claude: `name`, `description`, текст). Находятся
автоматически в: `%APPDATA%\AgentUmimiy\skills\<имя>\SKILL.md`, `~/.claude/skills`, навыки в плагинах
Claude и `.claude/skills` в проекте. Агент сам загружает нужный навык по описанию и следует ему.

### Агент работает в браузере

Агент открывает сайт в **настоящем окне браузера**, читает его, нажимает кнопки и заполняет формы (вы
видите, что происходит в окне). На Windows используется **Edge** (или Chrome), ничего устанавливать не
нужно.
- Браузер открывается в **отдельном профиле** (`%APPDATA%\AgentUmimiy\browser-profile`): он не трогает
  пароли и сессии в вашем основном браузере. Если вы один раз сами войдёте на сайт, в следующий раз
  останетесь залогинены.
- **Каждый новый сайт** и **каждый ввод** спрашивают разрешение. Агент **не пишет в поле пароля**: пароль
  введите сами в окне.
- В режимах «Все вместе» и «Совет» браузер выключен. В настройках его можно отключить полностью.
- Текст страницы для агента — только информация: «командам» оттуда он не следует.

### Агенты знают друг друга

Каждый агент знает **полный список агентов** в приложении (спросите «какие есть агенты?» — он перечислит
всех) и при необходимости просит помощи у другого агента (`ask_agent`): например, «спроси у gemini».
Вызванный на помощь агент может только читать и сам другого вызвать не может. Строка `⇄` в чате
показывает, кто у кого спросил.

### Несколько бесед

Вверху — **вкладки** как в браузере: у каждой беседы своя история и своя папка проекта, они работают
одновременно (когда фоновая беседа завершается, на вкладке появляется зелёная точка). `＋` — новая
беседа, `×` — закрыть.
Беседы сохраняются при закрытии приложения (см. пункт «Сохранение» выше).

### Режимы

| Режим | Как работает |
|---|---|
| Автоматический | выбирает агента по ключевым словам в `routes` |
| Один агент | первый выбранный агент |
| Все сразу | все агенты отвечают параллельно |
| По очереди | каждый агент улучшает ответ предыдущего |
| Совет | отвечают все, агент-судья выдаёт единый вывод |

### Подключение FreeLLMAPI (локальный шлюз)

Если на вашем компьютере работает FreeLLMAPI (`localhost:3001`):
1. **Настройки → ＋ Добавить → Тип: «FreeLLMAPI — локальный шлюз»** (адрес заполнится сам). Или
   «Автопоиск» найдёт его сам.
2. Вставьте **API KEY** со страницы FreeLLMAPI (раздел **Agents**) в поле «API-ключ».
3. Кнопка **Список** получает модели шлюза — выберите одну, **Проверить** → **Сохранить**.

Ключ хранится только в файле настроек на вашем компьютере. Если модель не поддерживает файловые
инструменты (tools), приложение переходит в обычный чат.

### Локальные агенты

- Если работают **Ollama** (`localhost:11434`) и **LM Studio** (`localhost:1234`), «Автопоиск» добавит
  их модели.
- Если установлены программы `claude`, `codex`, `gemini`, `aider`, они тоже находятся автоматически.
- Любая другая программа: тип «Программа на компьютере», команда `мой-агент {prompt}`.

## 👨‍💻 Для разработчиков

### Запуск из исходного кода

Нужен Python 3.9+. Дополнительные библиотеки по желанию: `pypdf` (чтение PDF), `qrcode` (QR-код для
телефона) `pillow` (вставка скриншотов через Ctrl+V), `python-docx` и `openpyxl` (создание файлов Word и Excel).

```bash
git clone https://github.com/Ravshan1989/Agent-umimiy.git
cd Agent-umimiy
pip install pypdf qrcode pillow python-docx openpyxl
python app.py                              # окно
python app.py --cli -m broadcast "привет"  # терминал
python -m unittest discover -s tests -t .  # тесты
```

### Структура проекта

| Файл | Назначение |
|---|---|
| `gui.py`, `theme.py` | окно и дизайн (Tkinter) |
| `providers.py` | Claude, OpenAI, Gemini, Ollama, CLI-агенты |
| `stream.py` | чтение потоковых ответов |
| `writer.py` | создание файлов Word, Excel и текстовых |
| `preview.py` | живой просмотр созданных файлов (песочница) |
| `server.py`, `server_page.py`, `store.py` | режим веб-сервера: HTTP, страница, SQLite |
| `agentic.py`, `tools.py` | цикл агента и инструменты (файлы, команды, поиск) |
| `orchestrator.py` | режимы и помощь между агентами |
| `browser.py` | управление браузером (CDP) |
| `mcp.py`, `skills.py` | плагины и навыки |
| `remote.py`, `remote_page.py` | управление с телефона |
| `docs.py`, `attachments.py` | чтение документов и файлов |
| `detect.py` | автоопределение агентов |

Новый тип агента: унаследуйте `Agent` в `providers.py` и добавьте его в `KINDS`.

### Сборка .exe

- **GitHub Actions:** Actions → «Dastur yig'ish / Build» → Run workflow. Результат: `AgentUmimiy-Setup.exe` (Windows) и `AgentUmimiy-Linux-x86_64.tar.gz` (Linux).
- **Вручную (Windows):** `packaging\build_windows.bat` (нужен Python и, по желанию, Inno Setup).

Готовые пакеты есть для Windows и Linux (см. «Установка» выше). На macOS можно попробовать запуск из
исходного кода (`python app.py`), но там программа не тестировалась.
