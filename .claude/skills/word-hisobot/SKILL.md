# Word (.docx) hujjatlar yaratish ko'nikmasi

Foydalanuvchi rasmiy xat, hisobot, ariza, shartnoma yoki hujjat so'raganda:
1. `create_document` asbobini chaqiring va fayl nomiga `.docx` kengaytmasini bering (masalan: `hisobot.docx`).
2. Mazmunni toza Markdown formatida yozing:
   - `# Sarlavha 1`, `## Sarlavha 2`, `### Sarlavha 3`
   - Ro'yxatlar uchun `- band` yoki `1. band`
   - Jadvallar uchun standart Markdown jadvali (`| Ustun 1 | Ustun 2 |`)
   - Muhim tushunchalarni `**qalin matn**` bilan ajrating.
3. Yaratilgan fayl haqida foydalanuvchiga qisqa va tushunarli xulosa bering.
