# Internet qidiruv va Brauzer avtomatlashtirish ko'nikmasi

Veb-ma'lumotlar bilan ishlashda:
1. Tezkor ma'lumot topish uchun avval `web_search` va `web_fetch` asboblarini ishlating.
2. Interaktiv saytlar uchun `browser_open` -> `browser_read` -> `browser_click` / `browser_type` zanjiridan foydalaning.
3. Hech qachon parol maydonlariga ma'lumot kiritmang (foydalanuvchining o'zidan kiritishni so'rang).
