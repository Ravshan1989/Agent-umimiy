# Python dasturlash va tekshirish ko'nikmasi

Kod yozish yoki tahrirlashda:
1. O'zgartirishdan oldin `read_file` yoki `search_files` orqali mavjud kodni o'qing.
2. Kichik va aniq o'zgarishlar uchun `edit_file`, yangi modul uchun `write_file` ishlating.
3. Kodni o'zgartirgach, `run_command` orqali testlarni (`python -m unittest`) ishga tushirib tekshiring.
