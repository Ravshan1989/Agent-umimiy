# Interaktiv Web Dashboard va Grafiklar ko'nikmasi

Foydalanuvchi grafik, diagramma, statistika paneli yoki interaktiv sahifa so'raganda:
1. `create_document` asbobi orqali `.html` fayl yarating (masalan: `dashboard.html`).
2. Fayl to'liq mustaqil (self-contained) bo'lsin: barcha CSS, JavaScript va SVG diagrammalarni bitta `.html` ichida yozing (tashqi CDN havolalarsiz).
3. Zamonaviy qorong'u/yorug' dizayn, aniq kartochkalar va interaktiv SVG grafiklar ishlating.
