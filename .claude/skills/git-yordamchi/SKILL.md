# Git versiya nazorati ko'nikmasi

Loyihadagi o'zgarishlarni tekshirish va Git bilan ishlashda:
1. `git_info` asbobini `what="status"`, `what="diff"` yoki `what="log"` bilan chaqiring.
2. Commit qilishdan oldin barcha o'zgargan fayllarni va testlar natijasini tekshiring.
3. Commit xabarlarini qisqa, aniq va mazmunli tilda yozing.
